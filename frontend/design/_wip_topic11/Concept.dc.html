What Is a Network?

The postal analogy, made precise.

A network is a group of two or more devices connected so they can share information and resources — the digital version of a postal system.

Devices on a network are called nodes. They're linked by wired or wireless connections. Once connected, any device can send data to, or receive data from, any other device on the network — just like any address on a postal route can send or receive mail.

1Device connects to a shared network — wired or wireless
2Each device gets an identifiable address
3A device sends data addressed to another device
4The network delivers the data to the correct destination

Example: Sending a document from a laptop to a network-connected printer works exactly like a letter travelling from a sender's address to a recipient's address.

Why this matters for security Every device joined to a network becomes a potential entry point into that network. Understanding what a network is is the foundation for later understanding how attacks and defences work.
Key takeaway: A network exists so separate devices can act as one connected system instead of isolated islands.
